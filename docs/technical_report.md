**版本**: 1.0  
**日期**: 2026-11-16  
**字数**: ~9 页（含图表）

## 摘要

本报告介绍一种面向工业制造场景的**两层自进化系统**（受控 RSI），实现"漂移监测—诊断归因—策略选择—实验优化—评估上线—回滚"完整闭环。系统在三个工业任务上取得显著性能提升：气体识别 Macro-F1 0.7140 → 0.7519（+5.3%），轴承 RUL RMSE 681.16 → 452.64（-33.5%），发动机 RUL NASA 分数 5.823e9 → 3.448e9（-40.8%）。

---

## 1. 引言

工业模型长期运行面临数据漂移挑战，导致模型"失准"。本赛题要求构建**工业模型自进化系统**，在漂移数据流上自动维持并提升性能，实现**受控递归自改进（RSI）**。

### 1.1 核心挑战

1. **漂移多样性**：不同任务漂移模式不同（批次漂移、工况变化、长尾分布）
2. **信号缺失**：部分场景特征信号本身不足（如轴承退化信号弱）
3. **非对称惩罚**：C 题 NASA 分数对低估惩罚指数级放大
4. **合规约束**：不能使用验证集标签拟合统计量，不能获取隐藏测试标签

### 1.2 方法论贡献

1. **两道诊断闸门**：区分协变量漂移 vs 标签移位，识别信号缺失
2. **三道退化闸门**：防止策略退化为常数预测
3. **收缩折叠技术**：将后处理收缩精确折叠进检查点参数，无需修改预测代码
4. **LOBO 交叉验证**：发现单次 train/val 划分会给出与 LOBO 完全相反的结论

## 2. 系统架构

### 2.1 两层自进化机制

```
┌─────────────────────────────────────────────────────────┐
│                    策略层自改进                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ 漂移监测器  │→│ 诊断归因器  │→│ 策略选择器  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
│         ↓                                      ↓         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ 退化检查器  │←│ 实验管理器  │←│ 自进化循环  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    模型层自迭代                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ 检查点加载  │→│ 扩展训练器  │→│ 检查点保存  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 六步闭环流程

| 步骤 | 模块 | 功能 | 输出 |
|------|------|------|------|
| 1 | DriftMonitor | 漂移监测 | 漂移信号（质心距离、寿命空档、分段 bias） |
| 2 | DiagnosisAttributor | 诊断归因 | 根因（协变量漂移、跨轴承错位、长寿命低估） |
| 3 | StrategySelector | 策略选择 | 最优策略配置 |
| 4 | 扩展训练器 | 实验优化 | 新检查点 + 验证指标 |
| 5 | DegradationChecker | 退化检查 | 三道闸门结果 |
| 6 | 评估上线/回滚 | 决策 | 更新检查点或回滚 |

## 3. 漂移监测与诊断归因

### 3.1 A 题：批次质心漂移

**监测指标**：
- 批次质心距离：`||centroid_batch2 - centroid_batch1||`
- Oracle LDA 跨批次准确率：batch1 训练，batch2 测试

**诊断发现**：
- batch2 的 Acetaldehyde 质心离 batch1 的 **Ethanol（7.50）比离自己类（9.90）更近**
- Oracle LDA 跨批次准确率 **0.3663 < 随机基线 0.6007**
- **结论**：决策边界完全不可迁移，属于**协变量漂移**

**否决的方案**：
- 标签移位校正（BBSE/EM）：连 ORACLE 都只有 0.5912 < 基线 0.7140
- 目标端归一化（TENT/CORAL）：违反赛规"不使用验证集标签拟合统计量"

### 3.2 B 题：寿命空档 + 信号缺失

**监测指标**：
- 寿命空档检测：训练集寿命排序，检测 >200 分钟的空档
- 分轴承 MSE 占比：常数预测下各轴承的 MSE 贡献
- 特征信号强度：rms 与 RUL 的 Spearman 相关系数

**诊断发现**：
- 训练集存在 **532→2495 分钟寿命空档**，Bearing3_4（1514 分钟）正落中央
- Bearing3_4 占验证集 **90.2%**，MSE 贡献 **90.2%**
- Bearing3_4 的 rms 与 RUL 秩相关仅 **+0.11**（另两根轴承 +0.75/+0.96）
- **结论**：**信号本身缺失** + **跨轴承水平错位**

**否决的方案**：
- 工况归一化：推理端拿不到工况标签（`predict.py:34` 剥离 meta）；工况分类准确率仅 8.4% < 随机 33%

### 3.3 C 题：长寿命低估被非对称评分放大

**监测指标**：
- 分段 bias：[0,50)、[50,150)、[150,400)、[400,900) 四个区间的平均 bias
- NASA 非对称惩罚：低估惩罚 `exp(-d/13)`，高估惩罚 `exp(d/10)`

**诊断发现**：
- [400,900) 区间仅 **44 个样本**，低估约 **190 循环**
- NASA 惩罚 `exp(190/13) ≈ 2.2e6` 每样本，主导了整个分数
- **结论**：**长寿命样本稀少导致低估被非对称评分放大**

## 4. 三项最优策略

### 4.1 A 题：类平衡加权 + 高斯增强 + 余弦退火

**策略**：
- `sample_weight="invfreq"`：逆频率加权，每类权重 = 总样本数 / (类别数 × 该类样本数)
- `gauss_aug=0.5`：归一化空间高斯噪声标准差
- `cosine_anneal`：余弦退火，学习率下限 1e-6
- `epochs=250`, `batch_size=64`

**效果**：
| 指标 | 基线 | 最优 | 提升 |
|------|------|------|------|
| Macro-F1 | 0.7140 | **0.7519** | +5.3% |
| Accuracy | 0.8786 | 0.8979 | +2.2% |

**关键发现**：
- 余弦退火到 250 轮时学习率已衰减到 1e-6，模型自然收敛在最优点附近
- `bestEpVal=0.7522` vs `finalEpVal=0.7519`，gap 仅 0.0002，**不需要 SWA**

### 4.2 B 题：向训练集中位数收缩

**策略**：
- `shrink_a=0.45`：收缩系数
- `shrink_center="median"`：收缩中心为训练集中位数 758.50
- `epochs=120`, `learning_rate=0.01`, `batch_size=128`

**收缩折叠技术**：
```
目标:  p' = a*p + (1-a)*center
其中   p = out * target_scale + target_mean
展开:  a*(out*target_scale + target_mean) + (1-a)*center
     = out*(a*target_scale) + (a*target_mean + (1-a)*center)

=>  target_scale' = a * target_scale
=>  target_mean' = a * target_mean + (1-a)*center
```

**效果**：
| 指标 | 基线 | 最优 | 提升 | vs 常数 470.86 |
|------|------|------|------|----------------|
| RMSE | 681.16 | **452.64** | -33.5% | **-3.8%** |
| MAE | 563.11 | 385.40 | -31.6% | -6.2% |

**关键发现**：
- 收缩可精确折叠进检查点参数（误差 ~1e-13），**无需修改 predict.py**
- LOBO 交叉验证：a=0.45 时 macro 599.36，worst-bearing 1216.27
- 分轴承 RMSE：Bearing1_4 303→569（退化），Bearing3_4 572→447（改善）

### 4.3 C 题：长寿命加权 + 长时训练

**策略**：
- `sample_weight="rul-150x3"`：RUL > 150 的样本权重 × 3
- `epochs=300`, `learning_rate=0.003`, `batch_size=128`
- `cosine_anneal`：余弦退火

**效果**：
| 指标 | 基线 | 最优 | 提升 |
|------|------|------|------|
| RMSE | 52.87 | **50.54** | -4.4% |
| MAE | 38.90 | 35.96 | -7.6% |
| NASA | 5.823e9 | **3.448e9** | -40.8% |

**关键发现**：
- [400,900) 区间 bias 从 -194.33 降到 -189.75（改善 2.4%）
- 长时训练（1200ep）RMSE 更优（50.29），但 NASA 反弹到 1.152e10
- **权衡**：RMSE 与 NASA 存在 Pareto 前沿，300ep 是最佳折中点

## 5. 实验分析

### 5.1 方法论教训

#### 教训 1：单次 train/val 划分会给出与 LOBO 完全相反的结论

**现象**：B 题 log1p 目标变换在单次划分下 RMSE 582（identity 497），看似更差。

**LOBO 揭示**：log1p 在 7/9 根轴承上大胜（Bearing1_1: 83.89 vs 728.87），只输在两根超长寿命轴承上。

**根因**：公开验证集 90.2% 由 Bearing3_4 构成，不代表隐藏测试。

**教训**：按整根轴承划分的任务必须用 LOBO。

#### 教训 2："按验证集挑最优轮次"是隐式早停，数字系统性乐观

**现象**：C 题 `w2_150x3` 加权在 `@ep126` 时 NASA = 1.69e9（乐观数字）。

**诚实口径**：固定 300ep 训练结束后 NASA = 3.612e9，差距 2.1×。

**A 题对比**：
| 配置 | bestEpVal（乐观） | finalEpVal（可部署） | gap |
|------|-------------------|---------------------|-----|
| balanced aug0.5 cos250 | 0.7522 | 0.7519 | 0.0002 |
| balanced aug0.0 cos250 | 0.7302 | 0.6274 | 0.1028 |

**教训**：所有报告数字必须标注 `finalEpVal`（可部署）还是 `bestEpVal`（乐观）。

#### 教训 3：指标变好不等于方法有效，要检查是否退化成常数

**现象**：B 题保序校准给出 RMSE 461.57（低于常数下限 465.55），看似突破。

**诊断**：
- 校准后 IQR 仅 15.9（真值 IQR 839）
- p10~p90 挤在 31 分钟带内
- 分轴承 bias：Bearing1_4 +782.3，Bearing2_4 +664.2，Bearing3_4 +52.8
- 等价纯常数 842 的 RMSE = 490.37

**结论**：校准退化成常数，恰好对 Bearing3_4（真值均值 757）比较"顺"。

**教训**：三道闸门（预测 IQR vs 真值 IQR、分轴承 bias、等价纯常数 RMSE）防止策略退化。

#### 教训 4：pooled LOBO 会被巨型轴承污染

**现象**：B 题 pooled LOBO RMSE 1141.54（log1p），看似很差。

**根因**：Bearing3_1/3_2 各 2500+ 样本，留出时剩余训练集中位数从 851 崩到 424，常数预测自然爆掉。

**解决**：按寿命分组报告（short/mid/long），并同时看 macro（轴承等权）与 worst-bearing。

## 7. 结论与展望

### 7.1 主要成果

1. **两道诊断闸门**成功识别三类漂移的根因，指导策略选择
2. **三道退化闸门**防止策略退化为常数预测
3. **收缩折叠技术**将后处理精确折叠进检查点参数，零合规风险
4. **LOBO 交叉验证**揭示单次划分的误导性，提供更可靠的泛化估计

### 7.2 局限性

1. **A 题天花板**：Acetaldehyde 在 batch2 的决策边界不可迁移，0.7519 已贴近天花板
2. **B 题信号缺失**：Bearing3_4 的 rms 信号仅 +0.11，无法从特征预测
3. **C 题长寿命稀少**：[400,900) 区间仅 44 个样本，加权改善有限

### 7.3 未来工作

1. **多模态融合**：B 题结合频域特征、时频分析
2. **元学习**：A 题学习跨批次迁移的元策略
3. **主动学习**：C 题主动采样长寿命样本
4. **不确定性估计**：为每根轴承预测不确定性，指导收缩系数
