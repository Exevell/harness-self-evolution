## 3. 数据使用声明

### 3.1 使用的数据

仅使用平台下发的三份任务包：`cpu-a-guide-20261110-v1`、`cpu-b-rul-20261110-v1`、`cpu-c-guide-20261110-v1` 中的 `public/train.jsonl`、`public/validation.jsonl` 与 `checkpoint.npz`。

### 3.2 数据隔离

| 要求 | 状态 | 依据 |
|------|------|------|
| 训练只用 `public/train.jsonl` | ✅ | `train_ext.py` 只读 `--train` 传入的路径 |
| 验证集标签不用于拟合任何统计量 | ✅ | 漂移监测只用训练集特征与结构信息；常数基线用**训练集**中位数 758.5（可部署），验证集标签只用于闸门打分 |
| 未接触隐藏测试标签 | ✅ | 任务包目录下只有 `public/train.jsonl` 与 `public/validation.jsonl` 两个数据文件，不存在任何测试集文件；镜像只读这两个路径 |
| 未使用外部数据 | ✅ | 无任何网络抓取或外部数据集 |

### 3.3 关于"验证集标签"的边界说明

系统需要读验证集标签来计算 RMSE / Macro-F1，这是**评估**动作，与"用验证集标签拟合统计量"不同。为把边界做实，系统做了三件事：

1. 选轮次时**不看**验证集最佳轮（固定 epoch 数，不做隐式早停）；
2. 常数参照用训练集中位数，不用验证集中位数；
3. 验证集中位数算出的"预言机常数"（B 465.73 / C 79.87）只写进记录字段 `rmse_const_oracle`，**不参与任何判定**。

## 4. 外部服务与网络访问声明

| 服务 | 是否必需 | 触发条件 | 传输内容 |
|------|----------|----------|----------|
| PyTRIO 大模型 | 否 | 设置了 `PYTRIO_API_KEY`（或 `TRIO_API_KEY` / `OPENAI_API_KEY` / key 文件）时 | 诊断摘要、基线代码摘录（≤900 字符）、最近 3 轮历史摘要；**不含训练数据、不含验证集标签、不含检查点权重** |
| SwanLab | 否 | 人工执行 `upload_to_swanlab.py` 时 | 数值型指标与策略名 |

- Key 只从环境变量或指定文件读取，**不写入任何日志或实验记录**。
- 未设置 Key 或调用失败时，`llm.source` 记为 `heuristic`，流程继续，不重试轰炸、不上报敏感内容。
- 除上述两项外，镜像运行期间不发任何外部请求。

## 5. 安全可控声明（受控 RSI）

| 机制 | 实现位置 | 作用 |
|------|----------|------|
| 大模型动作空间受限 | `harness/llm_advisor.py`（策略白名单 + `PARAM_BOUNDS` 夹取） | 模型不能生成任意代码、不能越界改超参 |
| 三道退化闸门 | `harness/self_evolution.py`（`full_check` / `check_constant_equivalence`） | 拦下分布坍缩、常数等价、单轴承系统性偏移 |
| 物理回滚 | 未通过轮次不写入 `current_checkpoint` | 坏策略不污染后续训练 |
| 学习率下限 | `train_ext.py`：`max(lr, 1e-6)` | 防止数值不稳定 |
| 固定轮次 | 不使用验证集挑最佳轮 | 避免隐式早停与信息泄漏 |
| 全字段可审计 | 每轮写 `experiment_history.jsonl` | 任何一次回滚可被第三方复算 |

**实际拦截记录**：B 题 3/3 轮、C 题 3/3 轮被拦下，A 题 1/1 通过。拦截依据的具体数值见技术报告第 3.1 节。
