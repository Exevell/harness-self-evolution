## 0. 结论摘要（≤400 字）

**根因**：B 的目标是 `RUL=D_b−i`（`D_b`=整根寿命分钟）。绝对分钟在轴承间**不可辨识**——单帧 34 维特征不含 `D_b` 信息（LOBO 实测：D=2538 的 3_1 被预测 60~209，D=371 的 3_3 被预测 941~1211，与 `D_b` 无关联）。所以按绝对分钟训练的模型只能记住训练轴承的水平；换一根就系统性错位。**父模型在公开验证集 681.16，比"验证集均值常数"465.55 还差**，3_4 的 bias −427 分钟、预测 IQR 只有真值的 0.26。这就是"多训几个 epoch 没用"的机制。

**方法**：改为回归**寿命分数** `p=y/D_b`，用**单一寿命尺度先验** `c` 还原分钟 `ŷ=c·p̂`。这等价于目标仿射变换 `fit_target=c·y/D_b`，可完全折叠进赛题包固定的 `target_scale/target_mean`，**不改 model.py/predict.py**（可部署）。训练对 `c` 不变（标准化抵消），`c` 是纯事后标量。LOBO 的 σ_p 从 1.222（绝对分钟）降到 0.283（分数）。

**结果**：公开验证集 **681.16 → 441.00（−35.3%）**，MAE 563.11→326.89，耗时 4.8s，确定性。LOBO 495 个"随机 4 根轴承"子集仿真：**947 → 654（−31%）**。Lead 的朴素门槛是 481.75，本方案在同一 val 上再好 8%。

**推荐配置**：父检查点续训 + 目标 `c·y/D_b`（`c=1000`）+ 250 epoch × lr 3e-3 × 3 seed，`selected` 门槛 5% + IQR 比 ≥0.35。

**风险**：①`c` 是先验，若隐藏 4 根以长寿命为主需上调到 1300~1500；②短轴承被刻意牺牲（D=42/122 的单根 RMSE 反而高于其常数），靠 5% 守卫兜底；③epoch 数存在"val 偏好长训 / LOBO 偏好 250"的分歧（唯一需 lead 拍板的点）。

## 2. 数据解剖与根因（为什么 657–681 会原地踏步）

公开 train：9 根轴承 / 7032 行；val：3 根 / 1679 行。

| 集合 | 轴承 | D_b(分钟) | 行数 |
|---|---|---|---|
| train | 1_1 / 1_2 / 1_3 / 2_1 / 2_2 / 2_3 / 3_1 / 3_2 / 3_3 | 123 / 161 / 158 / 491 / 161 / 533 / **2538 / 2496** / 371 | 7032 |
| val | 1_4 / 2_4 / **3_4** | 122 / 42 / 1515 | 1679 |

`D_b` 跨 42–2538 分钟（60×），**ΣD²/ΣD（行加权平均水平）= train 1909 / val 1377 / 12 根合计 1806**。

**证据链**：

1. **验证集 90.2% 的行是 3_4，且 3_4 贡献 98% 的平方误差**（p​ooled RMSE 681.16 中 3_4 占 455.7k/463.8k）。只看 val 会被单根长轴承主导——这正是题面警告的陷阱。
2. **父模型比常数还差**：val 均值常数 687.97 → RMSE **465.55**；按轴承常数（=D_b/2 附近）→ 415.5。父模型 681.16。
3. **误差是 bias 不是 shape**：父模型按轴承 bias 1_4 **+166.5**、2_4 **+326.3**、3_4 **−427.4**；预测 IQR/真值 IQR = **0.26**（严重压缩）。用按轴承 oracle 仿射标定，3_4 的 RMSE 可从 710.8 降到 **379.9**——形状信息是有的，被水平错位吃掉。
4. **LOBO 证明绝对分钟不可迁移**（父配方，训 8 根测第 9 根）：3_1 **1303.6**（bias −1059.6）、3_2 **1406.2**（−1182.9）、1_3 **1046.8**（+843.0）、3_3 **853.6**（+756.3）。同一模型换一根轴承就完全失效。
5. **水平不可辨识（决定性负结果）**：LOBO 下"预测水平"与 `D_b` 无关联（3_1 预测均值 60~209 而 D=2538；3_3 预测 941~1211 而 D=371）。所以**不要试图从特征预测 `D_b`**——任何"预测寿命尺度"的路线都无信号。

**误差可分解为**：
```
RMSE² ≈ (1/3)·E[(c − D_b)²] + c²·σ_p²        （p 在轴承内近似 [0,1] 均匀，E[p²]=1/3）
        ↑水平先验误差              ↑形状误差
```
两个杠杆：把 σ_p 从 1.22 压到 0.28（已做到 4×），剩下的 `c` 只能做**贝叶斯折衷**（见 §4）。

## 3. 方法：寿命分数目标（唯一被证明可部署的目标重定义）

```
p = y / D_b ,        fit_target = c · p ,         ŷ = c · p̂
```
- `D_b` 由训练标签推出（每根轴承 `y` 的最大值+1；末次快照 RUL=0 是题面定义）。
- **可部署性**：`ŷ = logit·target_scale + target_mean`，故 `c·p` 只是把 `target_scale` 换成 `c`、`target_mean` 换成 `c` 的均值，**零代码改动**。
- **训练与 `c` 无关**：`fit_target` 的均值/标准差都正比于 `c`，标准化后抵消。所以 `c` 只需事后定一次，不参与训练（这点让后面的 c 决策可以精确离线扫描）。
- **σ_p 对比**（12 根轴承的分数空间 RMSE，越小越好）：绝对分钟 **1.222** → 分数目标 **0.283**（中位）/ 0.27–0.33。

**可部署性审计（题面要求分开标注）**

| 方向 | 结论 | 依据 |
|---|---|---|
| 目标仿射重定义（raw 分钟 / 分数×c） | **可部署** | 只动 `target_scale/target_mean` |
| log1p / sqrt / 幂目标变换 | **不可部署**（需声明） | 还原需 `expm1/x²`，冻结的 `Model.predict` 没有逆变换钩子 |
| 特征 log / robust 缩放 | **不可部署** | 只支持仿射 `(x−mean)/scale` |
| 逐轴承/历史特征（快照号、总快照数、id） | **禁止** | 题面明确禁止作模型输入 |
| hidden 24→128 零填充 | 可迁移但**无用** | 新单元 `w2=0` → 梯度恒 0 → 死单元，见 §6 |

## 4. `c` 的决策（本方案唯一的外部先验）

`c` 的最优值：`c* = E4[D] / (1+3σ_p²)`，其中 `E4[D]` 是"隐藏 4 根轴承行加权平均寿命"的先验均值。

- 12 根公开轴承的全部 C(12,4)=495 个 4 子集：`E[D]_sub` 均值 **1468**（中位 1903，p10 348，p90 2231）。
- `c* = 1468/(1+3·0.283²) = 1184`；**经验最优（495 子集 pooled RMSE 均值）在 900–1100**，与理论一致。

| 800 | 656 | 991 | 1051 | 424 |

**取 `c=1000`**：距子集均值最优仅 +0.3%，同时 val 也接近最优（372，次优 361）。平台 900–1300 内误差 ≤7%，是平顶区。
注意 **c 过大/过小两头都变差**（不是"越大越安全"）：低 c 会让长轴承欠预测，高 c 会让短轴承过预测，最差子集在两个方向都恶化。

## 6. 为什么 hidden 24→128 零填充没用（因果解释）

父检查点 `hidden=24`。把 `w1` 补零列、`b1` 补零、`w2` 补零行是**函数保持**迁移（合法），但：
新增隐藏单元的激活 `tanh(0)=0` → `w2` 新行的梯度 `= h_new^T·δ = 0` → `w2` 新行永远为 0 → 回传到 `w1` 新列的梯度也恒为 0 → **新单元是死单元**。想激活必须打破对称（给 `w2` 新行加小扰动），那就不再是函数保持迁移。实测 LOBO 751（h128）/738（h64）都劣于 24 的 654，说明**容量不是瓶颈，水平不可辨识才是**。

### 9.2 「不劣化就不提交」守卫（针对上一版 3 轮倒退）

```
① 永远先在**当轮** public validation 上评测父模型（跨 stage 分数不可比）
② 候选必须 gain ≥ 5% 且 预测 IQR 比 ≥ 0.35，否则 selected="parent"、checkpoint_path 指回父检查点
```
**守卫实测**：把验证投影换成"只有短轴承 1_4"（父 242.0 vs 候选 577.7，gain −138.7%）→ 正确返回 `selected="parent"`、`model=None`。这正是上次 r5/r8/r10 该走的分支。

### 9.3 stage 投影"逐轮追加轴承片段"的兼容（重要）

平台 train 行数 7032→7048→7156、val 1679→1683→1710，说明会追加**片段**。片段不带 RUL=0 行时 `D_b=max(y)+1` 会严重低估（实测：Bearing2_1 的 16 行中期片段，真 `D_b=491`，只用 max(y)+1 得 **292**）。已实现三级恢复：
1. 组内存在 RUL=0 行 → `D_b=max(y)+1`（精确）；
2. 否则用 id 里的快照号 `D_b = y + i`（**精确**，实测 292 → **491**；快照号只用于还原标签尺度，绝不进模型输入）；
3. 都没有 → 退回 `max(y)+1`。
分组用 id 前缀，失败则用"相邻 y 差值≠−1"切段，再失败则整份当 1 根。`configuration.inconsistent_scale_groups` 会暴露异常。

### 9.4 风险与 lead 决策点

1. **`c` 是先验，不是估计**（最大风险）。若隐藏 4 根以长寿命为主（`E[D]≈2200`），`c=1000` 会欠预测，长轴承单根 RMSE ≈ 700–950；按 §4 表，`c=1500` 使子集均值 +16%。**建议**：若 lead 判断隐藏集含 ≥2 根 2000 分钟级轴承，把 `C_LIFE` 改 1300–1500（单行常量）。
2. **短轴承被刻意牺牲**。若某 stage 的公开 val 恰好是短轴承主导，候选会被 5% 守卫拒掉（无增益也无损失）——这是设计意图，不是 bug。
3. **epoch 数是唯一存在协议分歧的旋钮**：val 偏好 600–1200ep（308–329），LOBO 偏好 250ep（654 vs 716–724）。按任务"选型一律用 LOBO + worst-bearing"取了 250ep。若 lead 更信 public val，把 `EPOCHS` 改 1200、`SCHEDULE="cosine"`，val 会变成 ~404（但 LOBO 预期 +10% 变差）。
4. **续训初始化惩罚**：合规必须从父检查点续训，比从零训练在 val 上差 +40~70（441 vs 372）。试过延长训练/重置输出头可小幅弥补，但"重置输出头"处于"续训 vs 重训"的合规灰区，**未采用**。
5. **片段恢复依赖 id 格式** `..._s<数字>`。若平台改 id 格式且片段无 RUL=0 行，`D_b` 会低估 → 整体过预测；届时把 `USE_SNAPSHOT_INDEX` 与 `inconsistent_scale_groups` 一起看。

### 9.5 预期隐藏增益

- 方法层（LOBO 495 子集仿真）：**947 → 654（−31%）**，worst-bearing 1406→1104。
- 部署层（含父检查点续训惩罚，val 上 +19%）：**预期隐藏 RMSE ≈ 650–780**，相对"绝对分钟"家族（≈950）**提升约 20–30%**。
- 相对上一版平台实测最好 657.6：预期同口径下降 10–25%（但**隐藏值不可跨 stage 比较**，只能看趋势）。
